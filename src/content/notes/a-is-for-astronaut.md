Built a website with Astro.

This is the first post on this website. I wanted somewhere simple to put notes, experiments, and things I happen to find interesting, so I built one.

## Why Astro?

The site is intentionally small. There is no database, no client-side framework, and no complicated publishing system. Markdown files become pages, and Astro takes care of the rest.

A typical article starts with some frontmatter:

```yaml
---
title: A is for Astronaut
pubDate: 2026-08-13
tags: ["meta"]
draft: false
---
```

The rest is just Markdown.

That means I can write **bold text**, *italic text*, or `inline code` without having to think much about the underlying HTML.

### Code

Code blocks are useful for the occasional snippet:

```ts
const greeting = "Hello, world!";

console.log(greeting);
```

They also make it possible to write about code without having to turn every example into an image.

## A little more text

A paragraph should be long enough to make the typography worth looking at. This one is mostly here for that reason. When reading an article, the details of the interface should become uninteresting after a while: comfortable line length, sensible spacing, readable text, and enough contrast to keep going.

There should also be enough vertical space to make scrolling feel natural. Headings, paragraphs, lists, quotations, and code blocks should each have their own rhythm rather than becoming one undifferentiated column of text.
